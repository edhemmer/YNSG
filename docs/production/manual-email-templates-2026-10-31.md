# Manual branded email library — 31 October 2026

Owner request: expand the personal-reply area into a full set of natural, neighborly email templates with calls to action, independent of normal automations. This release provides 33 editable templates across personal follow-up, visit planning, thanks/feedback, honest reviews/referrals, seasonal services, re-engagement and holidays. The library appears in the YNSG request detail and Marketing destination. It intentionally uses the existing approved YNSG brand and is not shown for another company.

Each template has an editable subject, message, CTA wording and destination. Search matches its purpose and content. Ordinary requests use approved service/request URLs; review requests require an actual review URL, and reply buttons require the owner's business reply email. No review profile, date, discount, availability or completed-work fact is invented. Leaf handling stays general; mulch supplier prepayment, customer water, snow limits and cleanout fees remain accurate. Owners check the actual job and recipient before using a draft.

Branded table-based HTML uses the official logo and navy/forest/gold/cream palette, readable body text, a clear button and contact footer. Escaping and a sandboxed preview prevent draft text from becoming executable HTML. CTA links accept validated HTTPS or a single mailto address, without credentials, header parameters or encoded mail-header control characters. Owners can copy plain text, copy rich HTML where supported, download an HTML file or open a bounded plain-text mailto draft. Long drafts use copy/export. No mail provider, automation, queue, bulk send, paid AI or delivery-tracking mutation is activated. External email delivery is not inferred from copying or opening a mail app. Actual client formatting/owner acceptance remains separate.

Edited drafts require deliberate replacement and participate in workspace unsaved-entry protection. Copy completion compares the exact subject/body/CTA/recipient snapshot; a late copy cannot acknowledge newer edits. Company switches remove the YNSG draft. Preset templates do not persist customer data, and no custom-template database or new API/schema is introduced. Downloaded drafts are owner-controlled local files.

Local Chromium: 12 viewport/theme/text-size combinations, all 33 templates, 420 stages and zero readability findings/automatic writes. Cases include missing/unsafe CTA destinations, safe branded preview, cancelled replacement preserving edits, deferred copy followed by newer edits, rich clipboard, HTML download, long-mailto fallback and company isolation. Template tests cover unique purposes, all CTA paths, escape handling and service limits. Required CI includes the actual browser suite. Exact-head Linux/native PostgreSQL release checks, tested-tree merge, both deployment SHAs and read-only live checks remain publication requirements.

Related owner walkthrough fixes: request detail removes the internal service-radius block and unnecessary lookup, shows the saved next-step explanation and names the actual estimate/approval action. Work view links straight to the approval section. The agreement form explains phone/in-person/text/email evidence and keeps explicit recording, current quote versions, permissions, double-submit protection and uncertain-result reconciliation. Local Chromium passed 156 owner mobile interactions and 56 full field-journey cases using isolated fixtures; choosing an approval note never saves it automatically.
