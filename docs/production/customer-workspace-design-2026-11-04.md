# Customer workspace design — November 4, 2026

WEB-10 remains working. The owner reported that customer intelligence looked like an unstructured report: full-width service rows, oversized gaps and undifferentiated buttons. This release replaces that layout with a responsive customer-card workspace. Company totals are labeled separately from search results; each card shows the latest request, request count and compact service counts. Detailed task history and counting/marketing explanations remain available on demand. A record opens through the existing exact-customer callback. Search, clear, retry and pagination retain the existing scoped read contract.

Shared secondary controls gain a defined border, restrained surface and pointer/keyboard feedback. The customer search has a distinct primary action; customer-card actions have an arrow and branded treatment. No new fonts, libraries, external AI calls, business mutations or public website changes are introduced. Real records and permission logic are unchanged.

Validation scope: existing retry, cross-company late-response and exact-customer tests; actual rendered 320/390/768/1366 layouts in light/dark at 100% and 200% text; multi-card desktop versus stacked phone layout; search clearing; no inactive pagination on a single page; no non-GET or external requests. Synthetic browser captures are private artifacts. An initial 200% utility-button overflow was corrected and rerun. Full release and native PostgreSQL CI, surrounding navigation/field checks and deployed-SHA verification are required before production publication. Actual owner phone/iPad and performance acceptance remain open; this is not whole-product completion.

Surrounding regression check: the end-to-end field script and mobile-owner script still expected the removed separate approval form from before the prior one-step quote release. They now exercise Save agreed quote and prepare job and retain the no-premature-work/no-extra-write assertions. The complete local Chromium field journey passed 56 cases; workspace navigation and invoice checks passed 146 cases.
