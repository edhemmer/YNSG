# Job companion — focused field experience upgrade

Advance WEB-09/WEB-10 with a connected, free owner-support flow. Preserve canonical scheduling, agreement, work, invoice, payment, permission and interrupted-command behavior. No provider, paid model, automatic outreach or schema migration is introduced.

## Research and differentiation

Official product references checked October 30, 2026: [Jobber AI Voice and Chat](https://help.getjobber.com/en/articles/jobber-ai-voice-and-chat-beta/), [Housecall Pro customer profile summary](https://help.housecallpro.com/en/articles/9764383-customer-profile-overview), [Housecall Pro AI Team](https://help.housecallpro.com/en/articles/9311875-ai-team-overview), and [ServiceTitan Field Pro mobile features](https://help.servicetitan.com/docs/field-pro-features-available-on-mobile). They emphasize in-context actions, summaries and job preparation. Availability and charging vary by plan/provider; no free standalone equivalence is claimed.

YNSG’s differentiation for a solo owner is a small set of contextual tools in the existing job: prepare the actual requested task, discuss a clear next step with the customer, or choose a referral. It uses saved job state and existing sourced guidance instead of a general chat screen or invented AI confidence score. Comparative superiority requires owner usability evidence; this release makes no market-leading or 95%-autonomous claim.

## Scope and acceptance checklist

- [x] Relevant existing Field guide topic/preflight opens for the actual task; unsupported tasks have an honest fallback and do not inherit unrelated repair instructions.
- [x] A bounded read-only job context selects professional, neighborly customer-update proposals. Updates remain editable/copy-only, with no automatic send or saved delivery claim.
- [x] A deliberately chosen referral populates only public contact details in the customer draft; private notes, source, address, vetting evidence and photo URLs are excluded.
- [x] Manual draft edits survive support-tab changes. Close/discard, company changes, denied access and unknown network writes preserve the existing safety behavior. Clipboard success does not imply a sent message.
- [x] The existing Today priority is explained without adding another dashboard or changing queue ordering/authority.
- [ ] Types, lint, executable contracts, isolated behavior tests, real phone/desktop/theme/enlarged-text checks, complete release/native PostgreSQL CI, tested-tree merge and live production checks pass.

The owner’s real phone/iPad and real-work acceptance remain human evidence. Existing pricing, branding, services, customer workflow and free-only budget remain in force.

## Engineering evidence before publication

Local Chromium passed 12 phone/tablet/desktop × light/dark × normal/200% text cases and 84 job-companion stages with zero readability findings, no horizontal overflow and no automatic writes. Existing Owner network passed its eight combinations/60 stages, including interrupted-save recovery. Visual inspection reduced nested card padding and moved long source material behind a deliberate disclosure. Selected referrals are public-field projections; edited updates survive tool switches and deferred clipboard completion cannot acknowledge newer edits. Long email drafts use a copy fallback instead of an oversized mailto URL.

The real workspace session suite passed 15 cases, including owner-to-owner company context clearing and nested referral lookup preserving an unsent decline message. Unit tests cover current-phase wording, unsupported-task fallback, branding isolation, public-field exclusion, clipboard failure/snapshot handling, duplicate-free queue focus and independent decisions for an active job. Types, lint, generated API contracts, completion register, local PostgreSQL replay, dependency audit and the optimized CRM build passed. Full Windows test results retain the fourteen existing POSIX-file-mode/symlink backup limitations; required Linux/native PostgreSQL CI remains authoritative and no tests were suppressed.

No API or schema migration is introduced. Production release must still match the tested source tree and pass read-only live checks. Actual customer communication, owner phone/iPad acceptance and whole-product gate acceptance remain human evidence.
