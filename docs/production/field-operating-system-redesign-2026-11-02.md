# Field operating system restructure — 2 November 2026

Advances WEB-02, WEB-03, WEB-06 and WEB-10. This is a tested web maintenance release, not a declaration that every product, provider, legal, operations or native-distribution gate has passed.

## Scope and acceptance

- Same-company refreshes retain the mounted job and open entries. Company/identity/role changes still invalidate protected records. Initial reads are automatic; a manual retry appears only after a read failure. Browser tests hold and fail a refresh while checking the original job remains connected.
- A request needing scheduling opens the actual appointment form directly. One submit confirms/schedules through the existing conflict/travel/revision guards. The repeated opener, duplicate timing strip and non-interactive stage chips are removed. Requested work windows are labeled requested until confirmed. Customer scope/price agreement, actual work, invoice issuance and received payment remain distinct real evidence.
- The active job action, timer, completion, invoice and receipts stay together; supporting assignment, notes, files, history and optional prepared suggestions stay in Visit details. Contextual return navigation is company/request scoped and never reuses a previous entry point from the Jobs list.
- A single CRM design stylesheet sets lighter system typography, restrained hierarchy, compact controls and neutral informational panels. Status always has text; color is supplementary. Public website styling and issued financial documents are not restyled by this scope. Browser fixtures load the complete production stylesheet list in root-layout order.
- Owner network is now Service Rolodex. Primary entry is name or company, categories, phone, email and website. Optional notes, secondary contact fields, social links and firsthand vetting are retained in disclosures; existing stored metadata and explicit vetting attestation are preserved. Bare website domains gain https:// before the exact command body/fingerprint is created; entered www/http are retained and dangerous schemes remain invalid. No automatic www is invented, because that can change a valid hostname.
- Taxes is available directly from navigation and Settings. A service-review rejection has a direct setup link; reviewed API messages survive UI sanitization while unknown provider/database messages remain private.
- A healthy Calendar/Gmail connection shows Connected. Reconnect remains available under optional connection tools; an actual disconnected/expired connection retains the direct one-click entry to Google consent. No provider warning is bypassed and no sending control is silently enabled.
- Farm service, pricing and request pages remove the previous published dollar/day rate. They describe quoted work with the owner's requested four-hour minimum and keep arranged scheduling. No new farm rate, automatic billing rule or historical agreement change is introduced.

These are reference patterns, not claims of superiority or copied product assets.

Local lint, root/web types, executable-contract checks, completion integrity and 23-page SEO/673-link checks are required. Targeted recovery/permission tests and browser checks cover single appointment form, retained mounted job, Rolodex quick entry and URL normalization, contextual return, text contrast, 200% text, Google reconnect and financial authority. Windows-only encrypted-fixture/Git/symlink test constraints remain for exact-head Linux CI; do not suppress them. Both release jobs must pass, followed by tested-head merge, both production SHA/alias checks and live read-only smoke. No schema migration or paid service is introduced.
